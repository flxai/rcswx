# RCSWX browser example

A standalone reference consumer of `crates/rcswx-wasm`: real Rust computation in
one page-owned module worker, HTML/SVG views, and native-generated cached records.
It is not a TensorFlow/PyTorch runtime or a reproduction of the paper experiments.

From the repository root:

```sh
nix develop
make web-demo
```

Open the displayed URL under `/rcswx/`. `make web-build` produces `dist` here;
`make web-test` builds and checks that exact package in Chromium, Firefox and
WebKit using the browsers supplied by Nix. `make web-check` checks formatting and
TypeScript. `npm --prefix examples/web run format` formats the source and public
DTOs without rewriting generated fixture records. No globally installed npm or
WASM tools are needed.

## Controls

- **Example pair:** select one of five fully checked pairs. The manifest is an
  allowlist, not permission to combine arbitrary parents.
- **Offspring step:** step `k` applies exactly the first `k` selectable edits in
  application order, starting from prepared Parent 2. Previous/Next, range-input
  arrow keys and direct range selection control this slider.
- **Computation replay:** the separate event cursor and subproblem selector show
  recorded recursive DP state; they never move the offspring slider. Play
  advances this recording cursor. Matrix cells show top/left/corner candidates
  and actual retained traceback branches.
- **Focus or hover:** link occurrences across trees, tokens, operations, cells
  and child origins. Repeated logical IDs do not merge distinct occurrences.
- **Enable live computation:** initialize the local WASM worker, then use real
  retained plans. Sampling accepts a decimal integer seed and does not move the
  slider.
- **Cancel shared worker:** terminate the whole session; all its plan IDs expire.
  Enable live computation again to rebuild from the selected pair's input text.
- **Export recording:** download a local JSON bundle containing the trace and
  current child's lossless architecture JSON text. No model data is uploaded.

Cached native records are readable immediately, including when WASM loading is
blocked. Their exact input hashes and engine identity are retained. An error is
shown explicitly; an unavailable live result is never relabeled as successful
computation. Reduced-motion mode disables automatic playback. Text descriptions,
labels, table semantics and keyboard controls supplement the SVG presentation.

## Fixture source and regeneration

`fixtures/inputs.json` owns the five exact architecture pairs and explanatory
captions. `fixtures/recordings.json` is generated by:

```sh
make wasm-fixtures
```

The native Rust exporter validates every prefix, the prepared-second empty
selection, ordered structural endpoints and advertised surviving metadata. It
also checks `0 → n → 1 → n → 0` repeatability and records three fixed seeds.
The browser parity test compares the resulting plans, full event streams,
applications and samples against the built WASM artifact, excluding only runtime
plan IDs and build provenance. Do not edit the generated recording by hand.

`src/protocol.ts` and `src/client.ts` are the framework-independent consumer
boundary. `src/worker.ts` owns WASM, `src/render.ts` contains presentation helpers,
and `src/main.ts` owns this page's orchestration. `harness.html` is a real-worker
integration surface for the browser suite, not another computation implementation.

See [consumer documentation](../../docs/wasm.md) for the complete API, lossless
JSON/ID/seed rules, quota and cancellation semantics, CSP/MIME deployment notes,
license redistribution requirements, measurements and known limits. A website
can reuse the package/protocol while replacing all page components and styling.
